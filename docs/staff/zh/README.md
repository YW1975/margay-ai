# Staff 使用指南

> Staff 是你的私人助理：清楚你的事、你没吩咐时也会主动推进、守边界、留痕。
> 这份指南写给**使用 Staff 的人**（下文称「你」或「老板」），按「你对它说什么、它会怎么做」来讲。
> 以 2026-10-07 已发布的版本为准。

| # | 篇 | 讲什么 |
|---|---|---|
| 01 | [认识 Staff 与上手](01-getting-started.md) | Staff 是什么、第一次怎么报到上岗、开会话自动上班 |
| 02 | [在微信 / 飞书 / 企微里找它](02-reaching-staff-in-im.md) | 接入 IM、私聊和群里的不同规矩、下线与忙碌、在 IM 上批待批 |
| 03 | [每天的节奏](03-daily-rhythm.md) | 早报、到点提醒、会前提醒、下班总结、快出事时当场提醒 |
| 04 | [记事、日程与委派](04-todos-calendar-delegation.md) | 待办、提醒、日程本、和你常用的日历同步、把活交给别的助手 |
| 05 | [长期嘱咐与「你能干啥」](05-standing-orders-and-capabilities.md) | 立规矩、问它会什么、做不到时的求助单、它自己升级的边界 |
| 06 | [守边界与留痕](06-boundaries-and-audit.md) | 对外发送要你同意、敏感信息挡死、不能偷改自己的程序 |
| 07 | [没收到消息怎么办](07-troubleshooting.md) | 没收到提醒 / 早报、飞书登录快过期、后台程序、怎么看它现在能做什么 |
| 08 | [命令速查](08-command-reference.md) | 给装机、排错或开发看的命令清单（日常不用记） |

**一句话用法**：像对一个靠谱的助理那样直接说话——「帮我记一件事」「明天下午 3 点见老卢」「每天 18:00 给我发下班总结」「这个 PPT 找谁做」「你能干啥」。不用记命令。
