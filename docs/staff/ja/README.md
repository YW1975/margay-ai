# Staff 利用ガイド

> Staff はあなた専属のアシスタントです。あなたの仕事を把握し、指示がなくても自分から進め、越えてはいけない線を守り、記録を残します。
> このガイドは **Staff を使う方**（以下「あなた」または「ボス」）向けに、「Staff に何と言えば、どう動くか」という形で説明しています。
> 2026-10-07 時点でリリースされているバージョンに基づいています。

| # | 章 | 内容 |
|---|---|---|
| 01 | [Staff を知る・使い始める](01-getting-started.md) | Staff とは何か、初回の「着任」手続き、セッションを開くと自動で出勤 |
| 02 | [WeChat（微信）/ Feishu（飛書）/ WeCom（企業微信）で呼ぶ](02-reaching-staff-in-im.md) | IM の接続、個人チャットとグループでのルールの違い、オフラインと取り込み中、IM 上での承認 |
| 03 | [毎日のリズム](03-daily-rhythm.md) | 朝のブリーフィング、時刻指定のリマインダー、会議前リマインダー、終業サマリー、トラブルになりそうなときのその場での通知 |

**ひとことで言うと**：頼れるアシスタントに話しかけるように、そのまま話しかけてください。「これをメモしておいて」「明日の午後 3 時に盧さんと会う」「毎日 18:00 に終業サマリーを送って」「この資料（PPT）は誰に作ってもらうのがいい？」「何ができるの？」。コマンドを覚える必要はありません。
